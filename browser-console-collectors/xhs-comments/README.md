# 小红书评论收集器

`collect_comments.js` 是浏览器控制台脚本。安装后，它会在**当前标签页**监听页面自己发出的评论分页请求，从响应中提取已加载的评论和楼中楼回复，用评论 ID 去重，并在本机导出 JSON。它不会主动翻页、访问其他帖子或向外部服务器发送数据。

## 使用

1. 打开你有权查看的目标帖子页面，按 `F12`，切到 **Console（控制台）**。
2. 复制 `collect_comments.js` 的全部内容并执行。看到“评论收集器安装成功”后，重新打开帖子或刷新页面，再滚动评论区、展开需要的回复。
3. 在控制台输入 `xhsCommentsStatus()`，查看当前捕获数量与简要表格。
4. 输入 `exportXhsComments()`，下载 JSON；输入 `resetXhsComments()` 可清空当前标签页中的已收集记录。

导出的每条记录可能包含评论 ID、父评论 ID、帖子 ID、昵称、评论文本、时间、页面显示的 IP 属地、点赞数等。**这份导出文件包含他人的信息，不属于本仓库，也不应直接公开上传。**

## 工作方式与局限

脚本临时包装当前页面的 `fetch` 和 `XMLHttpRequest`，读取匹配评论分页路径的响应副本。它只看得到**安装后页面实际加载过的请求**；没有展开的回复或未滚动到的页面不会凭空出现。脚本不会自动卸载；刷新标签页即可恢复页面原有的网络函数。`resetXhsComments()` 只清空已收集记录，不卸载监听。

页面接口路径和返回字段可能变化，失效时应检查当前页面结构。请只在你有权使用的页面和目的范围内运行、保存及处理导出数据。
