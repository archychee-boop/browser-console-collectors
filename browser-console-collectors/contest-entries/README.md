# 绘画大赛报名资料收集器

`collect_entries.js` 是浏览器控制台脚本：按页读取一个活动分组的作品列表，再按作品 ID 读取详情，最后下载一份 JSON 供人工审核。**它不对作品作合格/不合格判定。**

## 准备

1. 用文本编辑器打开 `collect_entries.js`，填写开头的 `ACTION_ID`、`CATEGORY_ID`、`LIST_URL` 和 `DETAIL_URL`。公开版用占位符代替了原活动站点的地址和编号；没有配置时脚本会停止。
2. 用浏览器打开你有权使用的活动页面，按 `F12` 打开开发者工具，切到 **Console（控制台）**。
3. 复制整个 `collect_entries.js` 文件的内容，粘贴并执行。浏览器可能会提示你确认粘贴代码；确认前应阅读代码，且只在你信任的页面运行。
4. 等待控制台显示分页和详情读取进度。完成后浏览器会下载 `绘画大赛_成人组_...json`。根据浏览器设置，可能需要允许页面下载。

## JSON 包含什么

顶层有活动 ID、分组 ID、导出时间、总作品数及成功/失败计数。每个作品记录包含作品 ID、编号、作者/投稿显示名、标题、分组、图片地址、详情中的简介 HTML，以及读取失败时的错误文字。公开版**不保存接口的完整原始详情响应**，以免把审核不需要的字段一并导出。

脚本通过作品 ID 去重；遇到空页或整页没有新 ID 时停止，最多尝试 500 页。两次请求间默认等待 200 毫秒，详情读取失败会再尝试一次。实际接口字段、访问权限、跨域限制或限流发生变化时，需要按站点情况调整，不能保证适用于其他活动网站。

## 注意

- 下载的 JSON 可能包含投稿人姓名、作品内容或其他个人信息，只保存在经授权的位置，**不要上传到公开仓库**。
- 脚本没有登录凭据，不会绕过访问控制；请求设置为不携带浏览器凭据，只适用于经授权且允许这种请求方式的接口。
- 修改配置后先以少量页面核对字段和导出结果，再用于完整审核。建议核对总量、失败数及是否漏页。
