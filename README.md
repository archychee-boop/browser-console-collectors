# browser-console-collectors
# 浏览器控制台资料收集脚本

两个独立的 JavaScript 小工具，用于在浏览器开发者工具的 Console 中运行。它们整理活动页面或评论页面上可读取的信息，并在本机下载 JSON；仓库**不包含任何实际报名记录、作品详情或评论数据**。

| 工具 | 用途 | 使用前要做什么 |
|---|---|---|
| [绘画大赛报名资料收集器](contest-entries/README.md) | 分页读取指定分组的作品列表和简介，供人工审核整理 | 填写你有权访问的活动接口、活动 ID、分组 ID |
| [小红书评论收集器](xhs-comments/README.md) | 记录浏览页面过程中加载到的评论，按评论 ID 去重 | 在目标页面打开控制台，安装脚本后重新打开帖子 |

打开相应文件夹的 README，按步骤使用。代码不会代替人工审核，也不会自动抓取尚未在页面加载的小红书评论。运行结果会留在你的浏览器或本机下载目录。

这两个脚本来自一次实际工作流程，但公开版移除了活动网站的真实接口配置。网页接口会变化，因此运行前需要核对当前页面和授权范围。
